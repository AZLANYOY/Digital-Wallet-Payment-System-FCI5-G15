# Digital Wallet & Payment Management System

## Project Description

This project is an interactive C++ simulation of a digital wallet and payment management system.

The system demonstrates digital payment functions such as wallet top-up, money transfer, merchant payment, bill payment, transaction history and user management.

- Customer
- Merchant
- Admin
